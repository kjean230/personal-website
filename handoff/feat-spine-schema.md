Writes require `public.is_admin()` — true only when the JWT carries `app_metadata.role = 'admin'` (service-role/dashboard-settable only; `user_metadata` is tested to *not* grant it). Admin gets raw-row read + delete on reactions for moderation; nobody below `service_role` can update a reaction. Every grant is explicit (revoke-then-grant) because the hosted default no longer auto-exposes new `public` objects while the local image still does.
