### Decisions, one line each
- **Section derived from `kind`** → one canonical URL per entry; a slug under the wrong section 308s rather than 404ing or double-serving.
- **`?facet=` query parameter** (brief §4.2's idiom: shareable, one active at a time) over a path segment; the cost is that section pages render per request (data still cached hourly); `sectionHref` is the one place to change if the 1.5 s LCP gate ever needs `/experience` static.
- **Chips = All + non-zero facets** (a `/now` with five `(0)` chips is noise); counts always from `getFacetCounts`, never hardcoded.
- **`/hobbies` lists two kinds** because brief §4.3 is one tile; interests as `team` tags are `lane/content`'s.
- **Loaders return discriminated results;** only page files import `next/navigation` (unit-testable without Next; `notFound()` stays in the render path as Next prescribes).
- **No `metadataBase` / canonical `alternates` yet** — the domain is a plan §8 owner item.
