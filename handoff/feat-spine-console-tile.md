## Shipped
- **The three settled decisions, in the owner's words.** (1) **Where shell code lives:** `app/(explorer)/` holds **components only** — no `page.tsx`, no `layout.tsx` inside the group. That keeps plan §5's ownership boundary without a second route tree; S5 established that two route groups resolving to one path is a Next build error, and the architecture fixes one page file per URL. Nothing in `app/(explorer)/` creates a URL, and S7 adds no route. (2) **Renderer selection at the same URL:** **no mode switch.** The tile row is the enhanced rendering of the home page's existing section nav — the same `<ul>` of `<a>`s, wrapped by one client island. Recruiter and Explorer are the same markup until `feat/shell-boot-profile` ships the profile select; mode stays out of the URL. (3) **Zero-count sections:** **all six tiles show, with no counts.** Nothing is hardcoded because nothing is counted, `/hobbies` and `/now` keep their tiles and show S6's own "Nothing here yet." on their own pages, and — the load-bearing consequence — **`/` still reads no content and is still `○` static.**
- **The tile row — `app/(explorer)/section-tiles.tsx` (server) + `tile-row.tsx` (client).** `SectionTiles` renders the six brief §4.3 sections in `SECTIONS` order, each an `<a>` to `sectionHref(section)` with its Phase 0 icon inlined; `TileRow` is the island and receives them as **server-rendered children**, so no label, href or SVG crosses into the browser bundle and there is no second markup tree to keep in sync. Keyboard: Left/Right and Up/Down step (both axes, because the same row is horizontal on a wide viewport and a vertical stack on a narrow one), Home/End jump, and the walk wraps. `Enter` is **deliberately not handled** — the tiles are real `<a>`s and already activate on Enter (brief §2.2's "Enter = A"), so a listener could only duplicate the browser or diverge from it.
- **Escape = B = Back — `back-key.tsx` (client), mounted by `key-hints.tsx`.** It renders nothing and navigates *up* to a route-table URL (`/[section]` → `/`, `/[section]/[slug]` → its section, the same destination the crumb link points at). It uses `router.push(href)`, never `router.back()`: B is a hierarchical move to a fixed parent, whereas history is not — and `back()` on a deep link from a search result would send the visitor off the site entirely, which is the one thing "Back" must not do. **Trade-off recorded rather than hidden:** Escape pushes onto the history stack, so the browser's own Back afterwards returns to the page Escape left. The binding is mounted *by* the hint row so the shortcut and its visible cue cannot drift apart.
- **`keys.ts` is every pure key rule, and imports nothing** — `nextIndex(event, current, count)` and `isBackKey(event, editableTarget)`, plus the `EDITABLE_SELECTOR` both the rule and the island share. The islands keep only DOM wiring. This split exists because Vitest's environment is `node` with no jsdom (adding one is not S7's business), and a `"use client"` module importing `next/navigation` cannot be loaded under it at all. **A modified arrow is never ours:** `Alt+ArrowLeft`, and `Cmd+ArrowLeft` on macOS, is *browser back*, and the check lives in the tested function rather than the component precisely because swallowing it would break history navigation for the keyboard visitors the row exists for.
- **Icons come from `design/assets/icons/`, never copied — `(explorer)/tiles.ts`.** It ports `design/tokens/build.mjs`'s own `inline()`: drop the XML prolog, strip `id` / `role` / `aria-labelledby`, add `aria-hidden="true"` and `focusable="false"`. Stripping is load-bearing, not tidying — the source files carry a hard-coded `id="icon-<name>-title"`, so raw inlining would put duplicate ids in any page showing one glyph twice (S8's trophy rows will), and `role="img"` with a `<title>` would give each tile link a second accessible name over its visible label. It goes one step further than `build.mjs` and removes the `<title>` **element** too, which the specimen can keep because it has no text beside its glyphs but a tile cannot: it would render as a hover tooltip repeating the label. The map throws at import if a `SECTIONS` segment has no icon. **`now` is drawn by `tile-news.svg`**, not `tile-now.svg` — the section is `/now` but the icon was drawn for brief §4.3's "Now/News"; that map is the one place the mismatch is written down. `app/page.tsx`'s `kj-badge.svg` is deliberately left **unstripped**: it is a genuine image, not inside a link, and it scores 1.0 as it is.
- **The hint row — `key-hints.tsx` (server).** `A Select · B Back` using `hint-a.svg` / `hint-b.svg` with the key names in `<kbd>`; brief §2.1 lists corner button hints among the grammar this project borrows, and only the grammar — the glyphs are the hand-drawn Phase 0 ones, on this project's own palette. A `<p>` of `<span>`s, not a `<ul>` (two items announced as "list, 2 items" is noise, and `/` already has exactly two labelled landmarks). It appears only where the key it names does something: `/` gets the Select hint alone and **no** Escape binding, because there is nothing above it.
- **Presentation is Phase 0's, already drawn — `explorer.module.css`.** It ports the `.strip` tile row that `design/tokens/build.mjs` renders into `design/tokens/specimen.html`: faces on `--color-surface-raised` inside `--border-strong` at `--radius-sm`, flipping to `--color-primary` / `--color-on-primary` inside `--border-accent` with `--elevation-2` for the active item — DESIGN.md's rule that a fill appears only for the active item, in saffron, inside the outline. **The specimen's `72px`/`56px`/`32px` do not port**, because `design/**` is exempt from the token rule and this file is not; the same shapes are composed from `--size-*` and `--space-*`. Layout is one `repeat(auto-fit, minmax(min(100%, calc(var(--space-16) * 3)), 1fr))` grid, which gets brief §5.2's vertical stack with **no breakpoint at all** — worth stating because a custom property is illegal inside an `@media` condition, so a breakpoint could never have been a token. Transitions are colour and shadow only, never a positional lift, and need no `prefers-reduced-motion` query: `tokens.css` already zeroes every `--duration-*` globally.

## Deviated from plan
- **Brief §5's element-mapping table says the tile row is "Top-level sections, *recency-ordered*"; this ships in `SECTIONS` order (brief §4.3).** Flagged to the owner rather than silently resolved, and chosen by them. The reason it is not a free choice: ordering sections by their newest entry means reading content on `/`, which costs the home page its `○` and puts a database read on the site's most-hit, most-audited URL. `lib/routes/table.ts` has encoded §4.3 order since S5 and the PROMPTS S7 block asks for it.
- **The Resume link moved out of the section `<ul>`** into a sibling link below the row. It was a seventh `<li>` and would have had to become either a seventh tile (contradicting brief §4.3 and the settled six) or an oddly-styled non-tile inside a row whose keyboard `count` must match its DOM. Brief §2.2's "one action from anywhere" is unaffected — the site header carries it on every page — and DOM order keeps it the next Tab stop after the row, which the walk-through confirms. **This is a visible change to `/`.**
- **The hint row also appears on `/[section]` and `/[section]/[slug]`, which are otherwise S6's plain recruiter render.** That follows from mounting the Escape binding inside `KeyHints`: a keyboard shortcut with no visible cue is the accessibility problem the hint row solves, and pairing them means neither can be added without the other. **This is a visible change to S6's pages** and is called out here as a deliberate tick rather than a side effect. `/resume` is untouched — it is an audited URL and leaving its markup at the S6 baseline is worth more than consistency.
- **`next.config.ts` was edited for the first time in the repo.** Scope-wise this is not shell code, but the alternative was a deploy that 500s on `/experience` while every local gate stays green. See the Shipped bullet for why nothing local could catch it.
- **`CLAUDE.md`'s "No `\"use client\"` anywhere" is now false and was corrected, not deleted.** The JS-disabled property it was standing in for still holds; what changed is how it is enforced — by what the islands do, and by the script-stripping render, rather than by a grep returning empty.
- **No `renderToStaticMarkup`-based test existed in this repo before; `section-tiles.test.tsx` adds one.** It needs no new dependency (`react-dom/server` under the existing `node` environment, and `tsconfig`'s `jsx: "react-jsx"` compiles the `.tsx`), and it pins the JS-off promise — six real `<a href>`s and zero `tabindex` in the server's markup — as a unit test rather than leaving it to the manual smoke alone.
